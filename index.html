O Andromeda mudou tudo

Desde dezembro de 2024, a Meta usa um novo sistema de IA — o Andromeda — para decidir quem vê cada anúncio. E ele não funciona mais pela segmentação manual.

Agora é o criativo que encontra o comprador. O algoritmo lê a imagem, detecta o sinal emocional e distribui para quem está pronto para comprar.

O problema: criativos que parecem diferentes para o olho humano podem ser idênticos para o Andromeda. Quando isso acontece, eles competem pelo mesmo pool de entrega — CPM sobe, alcance cai.
